راهنمای GitHub Pages — اقیانوس ریاضی

نصب:
1) داخل ریپازیتوری روی Add file > Upload files بزن و همه فایل‌ها را (بدون پوشه، کنار هم) آپلود و Commit کن:
   index.html  style.css  app.js  data.json  hero.jpg
2) Settings > Pages > Source: Deploy from a branch > main و پوشه / (root).

ساخت توکن مدیریت (یک بار):
1) GitHub > عکس پروفایل > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token
2) Repository access: Only select repositories و همین ریپازیتوری را انتخاب کن.
3) Permissions > Repository permissions > Contents: Read and write
4) Generate را بزن و توکن را کپی کن (فقط یک بار نشان داده می‌شود).

مدیریت:
آدرس سایت را با /#admin باز کن، توکن را وارد کن. محصول و شماره و آیدی و عکس را عوض کن و «ذخیره و انتشار» را بزن.
تغییرات بعد از ۱ تا ۲ دقیقه برای همه نمایش داده می‌شود.
توکن را به کسی نده؛ فقط روی دستگاه خودت ذخیره می‌شود.
